# ☕ CupAndChai

A full-stack creator support platform inspired by Patreon, allowing users to support creators through secure one-time and recurring payments.

## 🚀 Features

* User authentication and authorization
* Creator profiles
* Secure payment integration with Razorpay
* One-time and recurring support options
* Responsive and modern UI
* Server-side rendering for improved performance
* Dynamic creator pages
* Dashboard for managing creator information

## 🛠️ Tech Stack

### Frontend

* Next.js
* React.js
* Tailwind CSS

### Backend

* Node.js
* Next.js API Routes

### Database

* MongoDB

### Payments

* Razorpay

## ⚡ Installation

```bash
git clone https://github.com/itsmohdzeeshan/cup-and-chai.git

cd cup-and-chai

npm install

npm run dev
```

## 🔑 Environment Variables

Create a `.env.local` file and add:

```env
MONGODB_URI=your_mongodb_uri
NEXTAUTH_SECRET=your_secret
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
```
